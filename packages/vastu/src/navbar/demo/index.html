<minimal-navbar>

A responsive navigation bar built with Lit. Below a breakpoint you choose, the links move into a slide-out menu behind a hamburger button.

Source on GitHub npm

Try it

The bar above uses breakpoint="600"; this window is wide. Resize it, pick a link, or switch the colours, which all come from CSS custom properties. The bar is position: sticky, so it stays at the top as you scroll.

Pick a link…

Use it

npm install minimal-navbar
// main.js
import 'minimal-navbar';

<!-- index.html -->
<minimal-navbar breakpoint="600">
  <a slot="brand" href="/">Acme</a>
  <a slot="link" href="/">Home</a>
  <a slot="link" href="/work">Work</a>
</minimal-navbar>
