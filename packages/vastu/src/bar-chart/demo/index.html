<bar-chart>

A bar chart built with Lit and D3. Give it new data and the bars animate to it, so it can follow live values.

Source on GitHub npm

Try it

data = 5 weekdays

Use it

npm install @firstprateek/bar-chart
// main.js
import '@firstprateek/bar-chart';

document.querySelector('bar-chart').data = [
  { group: 'A', value: 10 },
  { group: 'B', value: 19 },
];

<!-- index.html -->
<bar-chart width="500" height="400" max="20"></bar-chart>
